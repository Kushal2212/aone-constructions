# Requirements Document

**Project:** Company Website & Admin Panel
**Client:** A.one Brain Construction Pvt. Ltd.
**Location:** Pathari-Shanischare-1, Morang, Nepal
**Version:** 1.0 | **Date:** 2026-08-12

---

## 1. Purpose

Deliver an elegantly designed public website presenting the company, its services and completed work, with an admin panel for managing site content, client enquiries and client records.

## 2. Scope

In scope: public website, admin panel, CRM as described below. Anything not listed in Sections 4 and 5 is out of scope.

## 4. Website Requirements

| ID | Requirement | Description |
|---|---|---|
| W-1 | About | Company identity, tagline and team members. |
| W-2 | What We Do | Overview of the company's work. |
| W-3 | Services | The nine listed services, individually presented. |
| W-4 | Projects | Showcase of completed and ongoing work. |
| W-5 | Gallery | Image gallery of company work, managed from the admin panel. |
| W-6 | Testimonials | Client reviews and testimonials, displayed as set by the admin. |
| W-7 | Contact Form | Enquiry form capturing name, contact details and message; submissions stored and visible in the admin panel. |
| W-8 | Locations | Company location and service areas with map reference. |
| W-9 | Design | Elegant, professional, responsive presentation across desktop and mobile. |

## 5. Admin Panel Requirements

| ID | Requirement | Description |
|---|---|---|
| A-1 | Authentication | Secure administrator login; admin functions accessible only after login. |
| A-2 | Summary Dashboard | Landing screen on login summarising key figures — new and total contact enquiries, client counts by status, testimonial and gallery totals — with recent enquiries listed for quick access. |
| A-3 | Testimonial Control | Add, edit, publish, unpublish and delete testimonials. |
| A-4 | Gallery Management | Upload, organise and remove gallery images. |
| A-5 | Contact Enquiries | View, search and manage submissions received from the website contact form. |
| A-6 | CRM | Client records with contact details, enquiry history, status and notes, as well as other features as required |

## 6. Acceptance Criteria

Delivery is accepted when every requirement in Sections 4 and 5 is implemented and verified, content published from the admin panel appears correctly on the public website, and the site renders correctly on desktop and mobile devices.
